01

工作資料夾

選擇位置後，程式建立策略、版本、回測與分析資料夾。

02

AI 設定

此版支援 OpenAI API。使用自己的 Key 與 API 帳戶額度。

Key 由本地服務保存；Windows 使用目前使用者的 DPAPI 加密。模型處理時，策略與回測摘要會送交 OpenAI。

03

TradingView 連線

  1. 在 Chrome 登入自己的 TradingView 帳號。
  2. 載入或更新 Local Strategy Research Studio 擴充套件。
  3. 下載配對檔，在擴充套件「選項」匯入並啟用連線。

配對檔含本機連線金鑰，請留在自己的電腦。深度回測需要帳號方案支援。

使用標準 K 線；此版自動流程支援 UTC 時區。

04

策略來源

貼上分享網址後可直接開始研究，或先按「讀取對話」檢查內容。私人 /c/ 網址需要登入，請先在 ChatGPT 按「分享」，或改貼文字。

保留最新策略、交易規則與研究問題；有文字時以文字為準。最多 120,000 字元。

整理對話 → 產生策略 → 回測與核對 → 分析與修改 → 下一輪

也可以直接把檔案放進 strategies 資料夾。ELD／PLA 請先匯出文字。

05

測試條件與參數組合

接續對話時可留空，由 AI 依研究問題提出每輪候選參數。手動指定後，各輪使用你指定的組合。候選值以逗號分隔，名稱須與策略輸入標題一致。

進階參數設定（JSON）

1 組參數，最多 3 次回測。

固定使用 USD、固定口數、下一個 tick 撮合、每根 K 線結束計算，不啟用 Bar Magnifier。未模擬保證金限制。分批出場及加碼策略需另行適配。CSV／XLSX 無法核對時會停止。
