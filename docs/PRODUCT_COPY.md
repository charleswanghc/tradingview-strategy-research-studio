# 產品介紹與推廣文案

## 一句話

用自己的 TradingView 帳號和 AI Key，在本機完成策略撰寫、參數回測、報告整理與下一版修訂。

## 專案頁介紹

Local Strategy Research Studio 是一個 Windows 本地策略研究工具。選好工作位置，放入 MultiCharts 文字策略或描述新策略需求，再設定自己的 OpenAI API Key 與 TradingView 連線，就能開始有上限的研究循環。

程式逐版保存 Pine、測試每組候選參數、下載 CSV 與 XLSX，核對商品、成本、日期和交易數據後，再讓 AI 分析整批結果並提出修訂。每版程式與原始回測留在你的工作資料夾，方便比較、檢查與回溯。

目前是 Technical beta：Windows x64 免安裝桌面版、Chrome 橋接與 OpenAI API。首次需自行載入橋接並配對，深度回測需自己的 TradingView 權限。本工具協助研究，不提供獲利保證或自動實盤交易。

## 社群貼文

策略研究不只需要新程式，也需要可比較的測試。

本地策略研究室把流程接起來：放入文字策略或提出需求 → AI 撰寫 Pine → 程式測試各組參數 → 下載並核對報告 → AI 分析與修訂。

使用自己的 TradingView 帳號與 OpenAI API Key，資料保存在自己選的資料夾。Windows 免安裝 Technical beta 已開源，歡迎先用一版、一組測試驗證流程。

專案與下載：https://github.com/charleswanghc/tradingview-strategy-research-studio

## 30 秒示範旁白

先開啟本地策略研究室，選擇工作資料夾，填入自己的 AI Key。接著在 Chrome 登入 TradingView，載入橋接套件並匯入配對檔。你可以放入 MultiCharts 文字策略，或讓 AI 依需求撰寫 Pine。填好成本、日期、候選參數和測試上限，程式就會逐組回測、下載報告並核對，再交給 AI 分析與提出下一版。所有版本和回測結果都能在本機回查。
