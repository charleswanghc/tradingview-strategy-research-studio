# 首次使用

## 啟動應用程式

從 Releases 下載 Windows x64 ZIP，完整解壓縮，雙擊 `LocalStrategyResearchStudio.exe`。保留旁邊的 DLL、resources、locales 與 `TradingViewBridge`，不要只移動 EXE。視窗關閉會通知本地服務停止研究；意外中斷的測試不會自動重跑。

程式設定存於 Windows 目前使用者的應用程式資料目錄，與選定的策略工作資料夾分開。首次啟動沒有任何預設 API Key、帳號或策略。

## 選擇工作資料夾

在「工作資料夾」點「選擇位置」，選既有的父資料夾，再輸入工作資料夾名稱並按「建立／使用工作資料夾」。你也可輸入完整路徑，例如 `D:\StrategyResearch`。

程式建立 `strategies`、`versions`、`runs`、`analysis`。將自己的 MultiCharts UTF-8 文字策略放在 `strategies`，或使用面板匯入 `.txt`／`.pine`。來源不會被覆寫；工作資料夾可以保留在 Git 專案之外。

## 設定自己的 AI

在「AI 設定」輸入 OpenAI API Key 和該帳戶可用的模型 ID，再保存、測試連線。模型需支援 Responses API 與結構化 JSON 輸出；模型清單顯示帳戶可見 ID，並不代表所有模型都符合條件。Key 由 Windows DPAPI 加密保存，不會回填到畫面。

沒有 API Key 時，可選現有 Pine、取消 AI 分析，以程式執行參數回測。翻寫、新策略生成及 AI 分析需要自己的 API 額度。首次先使用 1 版、1 組測試，驗證流程再擴大。

## 連線自己的 TradingView

1. 在 Chrome 登入自己的 TradingView 帳號，將介面語言設為 English。深度回測是否可用由你的帳號權限決定。
2. 開啟 `chrome://extensions`，開啟開發人員模式，選「載入未封裝項目」，選下載包內的 `TradingViewBridge`。原始碼版本請選 `extension/dist`。
3. 回到研究室，在「TradingView 連線」下載 `pairing.json`。
4. 點 Chrome 工具列的研究室橋接圖示，匯入配對檔，勾選「啟用 MCP 連線」，按「儲存連線設定」。等待研究室顯示已連線。
5. 開啟或刷新 TradingView 圖表，回到研究室刷新分頁清單。輸入商品與週期後可建立研究專用圖表；選中該分頁並設定 UTC。

同一個 TradingView 分頁請只啟用一個自動回測擴充套件，以免重複操作。這份橋接有自己的擴充套件設定，原專案的設定不會被搬過來。桌面重新啟動會分配連接埠；若顯示未連線，重新下載並匯入本次配對檔。配對檔包含本機控制金鑰，請留在自己電腦。

TradingView 密碼只在 TradingView 自己的登入頁輸入。本程式不要求你提供密碼。若出現 Session disconnected，先在 Chrome 恢復登入／圖表，再刷新分頁狀態。

## 開始迭代

預設選「從 ChatGPT 對話接續研究」。貼上對話文字或 `https://chatgpt.com/share/…` 公開分享網址；只貼網址就可直接開始，也可以先按「讀取對話」檢查內容。有文字時以文字為準；修改已讀取的網址會清除原先讀取的文字，避免使用舊對話。私人 `/c/` 網址請先在 ChatGPT 按「分享」，或改貼文字。讀取失敗會停止並顯示原因，不會把登入頁當成策略。

填入這次要測的商品、週期（包含 1／5 分鐘）、日期、初始資金、口數、佣金與滑價。補充需求可以留空沿用對話；平台條件與補充需求優先。對話會自動整理為策略規則、未驗證假設、待測問題與第一版 Pine，接著回測、分析、修改並推進下一輪。每輪沿用研究摘要及歷次已核對結果。接續對話模式必須啟用 AI 分析；原始對話、研究摘要、版本、分析與停止原因會保存在本機。

接續對話時候選參數可留空，由 AI 在剩餘測試數內安排每輪候選；超過上限會停止而不裁切。手動填入的組合會固定沿用。也可改選「現有 Pine」、「翻寫 MultiCharts」或「AI 依需求撰寫」。手動候選參數名稱需與 Pine 的 input 標題一致，例如 `Length`，值可填 `10, 20, 30`。

設定版本上限及總測試上限。程式先列舉全部候選組合；超過上限會拒絕，不會偷偷只測部分。啟用 AI 時，閱讀資料傳送說明並勾選同意，再按「開始研究」。

回測時保持 Chrome 和研究室開啟，不要手動改動研究圖表的程式、商品或參數。程式逐版保存 Pine、逐組跑深度回測、下載報表、核對屬性與交易，最後交給 AI 分析。達到上限、AI 決定停止、策略與候選參數都未變更或驗證失敗時停止。

結果表顯示每組參數、淨利、回撤、勝率、PF 與報表。工作路徑、版本、實際涵蓋日期、停止原因及分析都可在面板或輸出資料夾查看。需要中止時按「停止研究」；中斷後先確認原圖表已停止，才開始下一次研究。

## 升級與備份

關閉研究室，解壓縮新版到新的程式資料夾；策略與報告保留在原工作位置。若橋接有更新，在 Chrome 移除／更新載入位置並重新配對。AI Key 綁定目前 Windows 使用者與本機環境，換電腦或使用者後請重新輸入。

只備份自己的工作目錄與需要的本機設定；不要把 AI 設定、配對檔或私人策略附到 GitHub Issue。
